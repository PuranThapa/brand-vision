# BrandVision

A 3D tee mockup studio that runs in the browser. Upload your logo, pick where it goes, choose a colour and turn the tee to see the print move with the fabric.

**Live demo:** https://brand-vision-theta.vercel.app/

## Features

- Round neck and V neck tees, with an optional polo collar
- Cropped and fitted cuts
- Logo upload (transparent PNG works best) on the front and back
- Click the logo to drag it, resize it from the corners
- Any tee colour, with cloth motion as you drag
- Save the view as a PNG

## Run it

No build step and no server. Download the repo and open `index.html` in a browser. It works offline.

## Built with

[Three.js](https://threejs.org/) r149 and plain JavaScript. The font is Manrope.
